This is an example note. It exists to show the serif running prose, the heading style and the math rendering, and it should be deleted once a real note takes its place.

The leading-order phase of a Mach–Zehnder atom interferometer in a uniform gravitational field is $\phi = k_\mathrm{eff}\, g\, T^2$, with the effective wave number $k_\mathrm{eff}$, the local gravitational acceleration $g$ and the pulse separation time $T$. For a Bragg transition of order $n$ the effective wave number is $k_\mathrm{eff} = 2 n k$, where $k$ is the wave number of a single laser field.

## Display math

Display equations sit on their own line:

$$
\phi = \vec{k}_\mathrm{eff} \cdot \vec{g}\, T^2 + \mathcal{O}\!\left(T^3\right).
$$

## Code

Inline code such as `fringe.phase(seq)` uses the monospaced face; blocks do too:

```python
phi = k_eff * g * T**2
```
