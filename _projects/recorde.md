Recorde is a Word add-in that renders LaTeX with MathJax 4 into vector SVG pictures and stores the LaTeX source inside the document, so every equation stays editable. It offers several maths fonts, journal-style equation numbering, TeX display spacing and a built-in macro preamble, and it works fully offline; nothing is sent to a CDN.

A companion CLI, `mjx-docx`, post-processes `.docx` files produced by python-docx, docx-js or pandoc without a running Word instance, so scripts and coding agents can generate documents that the add-in can open and edit.
